TasteWeave is a hackathon build for the Qloo Agentic Hackathon. The catalog, the neighbor archetypes, and every score on this page are synthetic and computed locally in your browser. No accounts, no tracking, no network calls.

The README documents exactly where the Qloo taste API would replace the synthetic dataset. No live integration is included and none is claimed.
